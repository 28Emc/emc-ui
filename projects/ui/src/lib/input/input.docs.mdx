# Inputs

Grupo de campos de formulario: `Input`, `Textarea`, `Select`, `Label`, `Field` y `FieldError`.
Los tres controles implementan `ControlValueAccessor`, por lo que funcionan con
`formControlName`, `ngModel` o formularios reactivos.

## Inputs compartidos (Field)

| Input      | Tipo             | Descripción                        |
| ---------- | ---------------- | ---------------------------------- |
| `label`    | `string`         | Etiqueta visible                   |
| `hint`     | `string`         | Texto de ayuda bajo el control     |
| `error`    | `string \| null` | Mensaje de error (borde/ring rojo) |
| `required` | `boolean`        | Marca el label con asterisco       |
