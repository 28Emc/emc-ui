# DatePicker

Selector de fecha con calendario en CDK Overlay, navegación de meses,
fechas mínimas/máximas y `ControlValueAccessor`. El valor se guarda en
formato ISO (`YYYY-MM-DD`) y se muestra como `DD/MM/AAAA`.

## Uso

<Source
  code={`<ui-datepicker
  placeholder="Fecha de nacimiento"
  [min]="minDate"
  [max]="maxDate"
  formControlName="birthDate"
/>`}
  language="html"
/>

| Input         | Tipo             | Descripción                  |
| ------------- | ---------------- | ---------------------------- |
| `value`       | `string \| null` | Fecha ISO `YYYY-MM-DD`       |
| `placeholder` | `string`         | Texto del campo vacío        |
| `min`         | `string`         | Fecha mínima permitida (ISO) |
| `max`         | `string`         | Fecha máxima permitida (ISO) |
| `invalid`     | `boolean`        | Estilo de error              |
| `disabled`    | `boolean`        | Deshabilita el control       |
